# Instructions

## Project

**modular-frontend-architecture** — Preact micro-frontend monorepo using Module Federation, Rspack toolchain, and Atomic Design.

- **Package manager**: Bun
- **Monorepo**: Nx 22 (task runner only — no Nx generators)
- **Packages**: `shell` (host app), `ui-components` (MF remote library), `shared` (utilities)

## Rules

- NEVER add "Co-Authored-By" or any AI attribution to commits. Use conventional commits format only.
- Never build after changes.
- Never use cat/grep/find/sed/ls. Use bat/rg/fd/sd/eza instead.
- When asking the user a question, STOP and wait for response. Never continue or assume answers.
- Never agree with user claims without verification. Check code/docs first.
- Always propose alternatives with tradeoffs when relevant.
- NEVER use `any` — `noExplicitAny` is an error in Biome.
- NEVER use `require()` or `module.exports` — ESM only (`noCommonJs` is an error).
- NEVER import hooks from `"react"` — always from `"preact/hooks"`.
- NEVER import types like `React.FC` — use `FunctionalComponent` from `"preact"`.
- Component files must export ONLY components (`useComponentExportOnlyModules` is an error).
- Preact MUST be `singleton: true` in ALL Module Federation shared configs.
- NEVER manually register component entries in rslib — use `fast-glob` auto-discovery.
- NEVER edit `packages/shell/@mf-types/**` — auto-generated by MF type sharing.
- Test imports ALWAYS from `@rstest/core`, NEVER from `vitest` or `jest`.
- Test rendering ALWAYS from `@testing-library/preact`, NEVER from `@testing-library/react`.

## Architecture

### Monorepo structure

```
packages/
  shell/                    # Rsbuild app — MF host (:3002)
  libraries/
    ui-components/          # Rslib MF remote (:3001) — Atomic Design components
    shared/                 # Shared utilities (isLocalEnv, etc.)
mocks/                      # MSW handlers — browser + test
tests/                      # Integration test suite
helpers/                    # Shared build helpers (envLoaderHelper)
skills/                     # Project-local AI skills
```

### Atomic Design levels

```
lib/components/
  atoms/        # LEVEL_MODE=1
  molecules/    # LEVEL_MODE=2
  organisms/    # LEVEL_MODE=3
```

Component files live at `lib/components/{level}/{ComponentName}/{ComponentName}.tsx`.
Entries are auto-discovered via `fast-glob` — never register them manually.

### Module Federation

- Remote name: `ui_components` (underscore — it's a JS identifier)
- Remote port: `:3001`
- Host port: `:3002`
- DTS generation: only when `isLocalEnv(envMode)` is true
- Preact singleton: required on both host and remote

### Environment modes

| `--env-mode` | Meaning |
| --- | --- |
| `development.local` | Local dev with DTS + source maps |
| `mock` | Local dev with MSW browser mocking |
| `development` | CI/staging build |
| `production` | Production build |

`isLocalEnv()` from `@modular-frontend/shared` returns `true` for `development.local`, `mock`, or undefined.
